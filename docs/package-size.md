# Windows 包体积与精简

2026-10-15，本机实测，单位 MiB（1 MiB = 1,048,576 字节）。源码文件很小，主要体积来自独立运行所需的 Python、Tk、cryptography 和 Qt/Deskflow 原生库。

| 项目 | 0.3.0 | 0.3.1 |
|---|---:|---:|
| Python 运行目录 `_internal` | 49.13 | 41.52 |
| 原生核心目录 `engine` | 45.16 | 36.52 |
| 完整便携目录（含文档/许可/源码） | 99.70 | 约 83.3 |
| 便携 ZIP | 39.56 | 约 34.0 |
| Windows 安装器（LZMA2） | 未提供 | 约 24.3 |

同为 ZIP 时下降约 14%；解压体积下降约 16%。安装器比 ZIP 更小还包含压缩格式的贡献，不能把这一差异全部归为代码优化。

本次移除重复 Tcl/Tk 副本，改用 PyInstaller 的依赖收集 hook，不再复制整个 cryptography 包的 Python 源文件；裁剪从未启动的上游 GUI、翻译、SVG/图片/样式插件。保留的核心/库不改二进制，Qt 主库、平台/网络/TLS 插件、许可证和对应源代码继续随包提供。托盘使用 Windows 原生 API，不增加运行依赖。

核心本身直接依赖 Qt Widgets/Network/Core；Qt Gui 也在导入闭包内，不能直接删除这些大文件。继续大幅降低体积需要改造控制层或重新构建核心，须重新验证跨平台输入、TLS、IPC 和系统权限，属于后续架构工作。
